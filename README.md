# Pokemons-EDA
Estudo de EDA sobre um dataset de Pokémon com pipeline completo de pré‑processamento e engenharia de features, implementação de modelos de machine learning para tarefas preditivas e um dashboard interativo (Dash/Plotly) para explorar dados, métricas e resultados do modelo.

Ficheiro principal: TUT1_TDIA_112779.123557.123554_VF.ipynb — EDA, pipeline ML e secção com código do dashboard.

Opcional: requirements.txt — dependências do notebook.

Pasta de dados: data/ — colocar aqui os ficheiros CSV usados pelo notebook.

Requisitos
Python 3.8+


Bibliotecas típicas: pandas, numpy, scikit-learn, matplotlib, seaborn, plotly, dash, jupyter

Estrutura do notebook
Carregamento de dados — leitura e verificação dos ficheiros.

EDA — estatísticas descritivas, distribuições, correlações e visualizações.

Pré‑processamento — limpeza, tratamento de missing values, normalização e engenharia de features.

Modelos ML — treino, validação e avaliação (ex.: classificação/regressão conforme objetivo).

Dashboard — código do app Dash para visualização interativa; instruções para correr localmente estão incluídas no notebook.
