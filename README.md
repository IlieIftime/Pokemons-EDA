Exploratory Data Analysis (EDA) study on a Pokémon dataset, featuring a complete preprocessing and feature‑engineering pipeline, implementation of machine learning models for predictive tasks, and an interactive dashboard (Dash/Plotly) to explore data, metrics, and model results.

Main file: TUT1_TDIA_112779.123557.123554_VF.ipynb — EDA, ML pipeline, and a section containing the dashboard code.

Optional: requirements.txt — notebook dependencies.

Data folder: data/ — place here the CSV files used by the notebook.

Requirements: Python 3.8+

Typical libraries: pandas, numpy, scikit‑learn, matplotlib, seaborn, plotly, dash, jupyter

Notebook Structure
Data loading — reading and validating the input files.

EDA — descriptive statistics, distributions, correlations, and visualizations.

Preprocessing — cleaning, handling missing values, normalization, and feature engineering.

ML models — training, validation, and evaluation (e.g., classification/regression depending on the objective).

Dashboard — Dash app code for interactive visualization; instructions for running it locally are included in the notebook.
